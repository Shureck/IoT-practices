# Руководство преподавателя

## Регистрация

1. На странице «Регистрация» выберите роль **«Преподаватель»**.
2. Заполните имя, email и пароль (не короче 6 символов).
3. Введите **«Код преподавателя»**. Его задаёт администратор сайта переменной `TEACHER_INVITE` в файле `.env`
   (см. [DEPLOY.md](DEPLOY.md)). Код нужен, чтобы преподавателем не мог зарегистрироваться любой желающий.

После входа откроется **«Кабинет преподавателя»** (пункт меню «Преподавателю»).

## Группы

* **«Новая группа»** → название (например, «ИКБО-01-24») → «Создать». У каждой группы свой код из 6 символов.
* Нажмите на код рядом с надписью «Код для студентов:» — скопируется **ссылка-приглашение** вида
  `https://<сайт>/register?group=КОД`. Студент, открывший её, зарегистрируется сразу в группу.
* Студент может вступить и позже: «Профиль» → «Код группы» → «Присоединиться».
* Удаление группы не удаляет студентов и их работы — они просто остаются без группы.

Работы студента без группы преподаватель не видит; на странице курса студенту показывается предупреждение об этом.

## Вкладка «Прогресс»

Матрица «студенты × практики» выбранной группы. Фильтр сверху — по модулям.

| В клетке | Значение |
|---|---|
| цифра | оценка, поставленная преподавателем |
| ✓ | работа сдана, все автопроверки пройдены |
| N % | работа сдана, но пройдены не все проверки (доля пройденных) |
| … | у студента есть черновик, но сдачи нет |
| · | не начато |

При наведении видно число попыток. Клик по клетке со сдачей открывает работу на проверку.
Кнопка **«CSV»** выгружает матрицу в таблицу (разделитель `;`, открывается в Excel): студент, email, XP и статус
каждой практики с оценкой.

## Вкладка «На проверку»

Очередь сданных работ без оценки, новые сверху. Галочка «показывать и проверенные» показывает все сдачи.

### Проверка работы

Работа открывается в полном верстаке только для чтения: схема, код, монитор порта, симуляцию можно запускать.
Сверху — результаты автопроверок (✓/✗ по каждой), число использованных подсказок и дата сдачи.

* **«Эталон»** загружает эталонное решение (код и схему) на место работы студента — удобно сравнить.
  Чтобы вернуть работу студента, обновите страницу.
* **«Оценить»** → оценка 2–5 (повторный клик по выбранной оценке снимает её) и комментарий студенту → «Сохранить».

Студент видит оценку и комментарий в задании («Комментарий преподавателя»), в «Моих попытках», на карточке практики
и в профиле.

## Вкладка «Дедлайны»

Выберите практику, срок сдачи и нажмите **«Назначить»**. Студенты группы увидят дату на карточке практики
(просроченная — красным). Дедлайн информационный: сдать работу можно и после него, дата сдачи видна в матрице.

## Как устроен зачёт

* **Задания с кодом** засчитываются, если скетч компилируется и проходит **все** автопроверки. Студент может
  нажимать «Проверить» сколько угодно (это не попытка), а «Сдать» сохраняет попытку — их число не ограничено.
* **Тесты** засчитываются от 70 % правильных ответов.
* **Опыт (XP)** начисляется один раз — за первую успешную сдачу. Каждая открытая подсказка уменьшает награду на 10 %,
  но не ниже половины.
* **Уровни** по опыту: Стажёр (0), Младший инженер (60), Инженер (240), Старший инженер (540), Ведущий инженер (960),
  Главный инженер (1500), Начальник станции (2160).
* **12 достижений** — за первые шаги, завершение модулей, кейсы без подсказок, прошивку настоящей платы и др.

Автопроверки выполняются на сервере тем же симулятором, что и в браузере. Эталонные решения студентам не отправляются.

## Если студент пишет, что «не работает»

* **Светодиод не мигает** — чаще всего нет второй `delay()` после `digitalWrite(..., LOW)`.
* **В мониторе «каракули»** — скорость монитора не совпадает с `Serial.begin(...)`; панель предлагает переключить.
* **«Авария ESP32»** — деление на ноль, выход за границы массива и т. п.; строка указана в сообщении.
* **Работа «зависла» при проверке** — бесконечный цикл без `delay()`; проверка прерывается по таймауту.
* Вкладка **«Проблемы»** внизу собирает ошибки компиляции и предупреждения симулятора (сгоревший светодиод,
  вход без подтяжки, перегрузка вывода).
* **«Сначала»** возвращает исходные код и схему практики; сданные попытки при этом сохраняются.

## Связь с лекциями

Практики идут по пяти лекциям курса (см. [PRACTICES.md](PRACTICES.md)). Код совместим с ядром ESP32 2.x, как на
лекциях (`ledcSetup`/`ledcAttachPin`), поддерживается и API ядра 3.x. Кнопка «W» в верстаке выгружает схему в формате
`diagram.json` для Wokwi.
