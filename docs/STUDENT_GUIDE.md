# Руководство студента

## Начало

1. Откройте ссылку-приглашение от преподавателя — код группы подставится сам. Или зарегистрируйтесь
   и введите код группы в «Профиле».
2. Перейдите в **«Курс»**: шесть модулей по лекциям, в каждом — лабораторные, домашние, кейсы и тест.
3. Без входа можно читать задания и запускать симулятор, но проверять и сдавать работы — только после входа.

## Верстак практики

```
┌ Задание / Компоненты / Свойства ┬────────── Схема ──────────┬── Код ──┐
│ сюжет, цели, автопроверка,      │  ESP32, детали, провода   │ Arduino │
│ теория, подсказки               ├───────────────────────────┤  C++    │
│                                 │ Монитор порта, Плоттер, … │         │
└─────────────────────────────────┴───────────────────────────┴─────────┘
```

* **«Запуск» (F5)** — компилирует скетч и запускает виртуальную ESP32. **Shift+F5** — стоп.
  Скорость симуляции — от 0.1× до 10×.
* **«Проверить»** — прогоняет автопроверки на сервере. Это не попытка, можно нажимать сколько угодно.
* **«Сдать»** — сохраняет попытку. Зачёт — когда пройдены все проверки. Опыт начисляется за первый зачёт.
* **«Попытки»** — история сдач с оценками и комментариями преподавателя; код любой попытки можно загрузить обратно.
* **«Сначала»** — вернуть исходные код и схему (сданные попытки останутся).
* Черновик сохраняется автоматически — в браузере и на сервере.
* Стрелки ◀ ▶ рядом с названием — предыдущая и следующая практика.

### Подсказки

Вкладка «Подсказки» открывает их по одной. **Каждая подсказка уменьшает награду на 10 %**, но не больше чем вдвое.

### Тесты

Отметьте ответ в каждом вопросе и нажмите «Отправить ответы». Зачёт — от 70 %. Пройти можно повторно.

## Схема

* **Добавить деталь** — вкладка «Компоненты»: клик ставит деталь рядом со схемой, можно и перетащить на поле.
* **Провод** — клик по выводу, затем по другому выводу. Пока провод тянется, клик по пустому полю добавляет изгиб,
  Esc или правая кнопка — отмена. При наведении на вывод видно его название и номер GPIO.
* Провода раскладываются **автоматически**: обходят детали, выходят из вывода перпендикулярно и не накладываются
  друг на друга. Провода одной цепи (GND, питание) сходятся в общую шину с точкой-узлом.
* **Двойной клик по проводу** — добавить точку, через которую он обязательно пройдёт; двойной клик по точке —
  удалить её. В свойствах провода — цвет и «Сбросить изгибы».
* **R** — повернуть деталь, **Del** — удалить, **Ctrl+D** — копия, **Ctrl+Z / Ctrl+Y** — отменить / вернуть.
* Колёсико — масштаб, перетаскивание поля — сдвиг, «Показать всё» — вписать схему в окно.
* В некоторых заданиях схема уже собрана и закреплена — меняется только код.

### Во время симуляции

* **Кнопка** нажата, пока зажата мышь; **Shift+клик** — зафиксировать нажатие. В свойствах кнопки можно назначить
  клавишу клавиатуры.
* **Переключатель** — клик. **Датчик движения** — клик «проходит» перед ним.
* Потенциометр, фоторезистор, DHT, дальномер, датчик газа — ползунки во вкладке «Свойства» (отмечены зелёной точкой).
* Схема «живая»: светодиод без резистора сгорит, вход без подтяжки «висит», перегрузка вывода — предупреждение.
  Значок «!» на детали и карточки внизу слева объясняют, что не так.

## Нижние панели

| Вкладка | Для чего |
|---|---|
| Монитор порта | вывод `Serial`, отправка строк в плату. Если скорость не совпадает с `Serial.begin`, будут «каракули» — как на настоящей плате |
| Плоттер | графики чисел из `Serial` (через пробел/запятую или `имя:значение`) |
| Анализатор | логический анализатор на 8 каналов с декодером UART (нужна деталь «Логический анализатор») |
| Сеть | журнал Wi-Fi, HTTP и MQTT; список сетей вокруг станции |
| MQTT | подписка и публикация в общий брокер — общайтесь со своей платой или с одногруппниками |
| Чат | чат станции, которым управляет «умный помощник» |
| Браузер | страница веб-сервера, запущенного на виртуальной ESP32 |
| Проблемы | ошибки компиляции и предупреждения симулятора; клик — переход к строке |
| Плата | настоящая ESP32: компиляция, прошивка по USB и монитор порта платы |

## Настоящая плата

Вкладка **«Плата»** (нужен вход, браузер Chrome, Edge или Opera на компьютере):

1. **«Скомпилировать»** — скетч собирается настоящим `arduino-cli` на сервере (ядро ESP32 2.0.17).
2. **«Прошить плату»** — подключите ESP32 по USB и выберите порт. Если прошивка не начинается — зажмите кнопку
   BOOT на плате. Если плата не видна — установите драйвер CP210x или CH340.
3. **«Монитор платы»** — вывод `Serial` настоящей платы.

Готовую прошивку можно скачать файлом `.bin`. Плата подключается к тому же MQTT-брокеру, что и симулятор:
адрес показан на сайте (порт 1883).

## Учебная сеть

| Что | Значение |
|---|---|
| Wi-Fi | `Samsung_IoT` / `IOT5iot5`, `Polar-Station` / `aurora2025`, `Wokwi-GUEST` (без пароля) |
| Сервисы | `weather.iot` (погода), `chat.iot` (чат), `time.iot`, `station.iot/telemetry`, `api.iot/echo`, `facts.iot` |
| MQTT | `mqtt.iot:1883` в симуляторе; работают и `broker.hivemq.com`, `test.mosquitto.org` |

Всё это описано в **«Справочнике»**: функции Arduino с примерами, распиновка ESP32 DevKit V1, компоненты, сеть
и частые ошибки.

## Песочница

Свободный режим без заданий: примеры («Мигалка», «Метеостанция», «MQTT-телеметрия», «Веб-сервер» и др.),
сохранение проектов (Ctrl+S), ссылка «Поделиться» — по ней откроется копия вашего проекта.

## Опыт и достижения

Опыт растёт за зачтённые работы и открывает уровни — от «Стажёра» до «Начальника станции». 12 достижений — за первый
свет, завершение модулей, кейсы без подсказок, прошивку настоящей платы и пару сюрпризов. Всё видно в «Профиле».

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| F5 / Shift+F5 | запустить / остановить симуляцию |
| Esc | отменить провод, снять выделение, закрыть окно |
| R / Del / Ctrl+D | повернуть / удалить / скопировать деталь |
| Ctrl+Z / Ctrl+Y | отменить / вернуть изменение схемы |
| Ctrl+S | сохранить проект (в песочнице) |
